# bug-free-waffle

## Taroker

A single-page browser game hosted from this repo. The whole thing lives in `index.html` and can be played directly by opening the file or by sharing a githack link.

### Play it (githack)

Live links served straight off this branch — no merge needed:

- https://raw.githack.com/Bush0Bear/bug-free-waffle/claude/setup-taroker-game-9Ck0x/index.html (dev, no caching)
- https://rawcdn.githack.com/Bush0Bear/bug-free-waffle/claude/setup-taroker-game-9Ck0x/index.html (CDN, cached — share this for the smoother experience)

To ship a new version, drop the updated HTML in as `index.html`, commit to this branch, and re-share the link. The `rawcdn` URL is cached for ~30 days unless the commit SHA changes — for a hard refresh, swap the branch name for the latest commit SHA.
