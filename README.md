# bug-free-waffle

## Taroker

A single-page browser game hosted from this repo. The whole thing lives in `index.html` and can be played directly by opening the file or by sharing a githack link.

### Play it (githack)

Once `index.html` is on the `Taroker` branch, friends can play at:

- https://raw.githack.com/Bush0Bear/bug-free-waffle/Taroker/index.html (dev, no caching)
- https://rawcdn.githack.com/Bush0Bear/bug-free-waffle/Taroker/index.html (CDN, cached — share this for the smoother experience)

To ship a new version, drop the updated HTML in as `index.html`, commit to `Taroker`, and re-share the link. The `rawcdn` URL is cached for ~30 days unless the commit SHA changes — for a hard refresh, swap `Taroker` for the latest commit SHA.
